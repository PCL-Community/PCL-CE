# Controls/MyMsg

自定义消息框（MyMsg）系列，命名空间 `PCL`，配合 `ModMain.MyMsgBox` 使用，替代标准 `MessageBox` 以统一启动器视觉风格。

## 本目录直接文件

- `MyMsgText.xaml(.cs)`：纯文本消息框。
- `MyMsgInput.xaml(.cs)`：带输入控件的对话框（获取用户输入）。
- `MyMsgSelect.xaml(.cs)`：选择对话框（提供可选项供用户挑选）。
- `MyMsgMarkdown.xaml(.cs)`：支持 Markdown 渲染的消息框（用于更新日志、长文本说明）。
- `MyMsgAuthServer.xaml(.cs)`：认证服务器选择对话框（用于正版登录时选择认证服务端点）。
