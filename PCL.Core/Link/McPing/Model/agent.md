# Link/McPing/Model 目录

MC ping 结果模型，位于命名空间 `PCL.Core.Link.McPing.Model`。

## 本目录模块

- **McPingResult.cs**：整体 ping 结果模型（MOTD、在线数、版本、延迟等）。
- **McPingVersionResult.cs**：服务器版本信息模型。
- **McPingPlayerResult.cs**：玩家信息模型。
- **McPingPlayerSampleResult.cs**：示例玩家条目模型。
- **McPingModInfoResult.cs**：Mod 信息结果模型。
- **McPingModInfoModResult.cs**：单个 Mod 信息条目模型。
