# Link/Scaffolding/EasyTier 目录

脚手架内 EasyTier 实体与信息，位于命名空间 `PCL.Core.Link.Scaffolding.EasyTier`。

## 本目录模块

- **EasyTierEntity.cs**：EasyTier 实体模型。
- **EasyTierMetadata.cs**：EasyTier 元数据模型。
- **EasyPlayerInfo.cs**：EasyTier 玩家信息模型。
- **PublicNodeDto.cs**：公共节点数据传输对象（可加入的公共中继节点）。
- **StunInfo.cs**：STUN 信息模型（NAT 类型/公网地址）。
- **CliNetTest.cs**：CLI 网络测试（探测 EasyTier 网络连通性）。
