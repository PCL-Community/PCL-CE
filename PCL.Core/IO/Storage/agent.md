# IO/Storage 目录

存储子系统，位于命名空间 `PCL.Core.IO.Storage`。提供内容寻址存储与高速缓存能力，底层可基于文件系统或 SQLite。

## 本目录模块

- **`HashStorage.cs`** — 基于哈希的内容寻址存储 `HashStorage`：`PutAsync` 写入内容并返回内容哈希键，`Get` / `Exists` 按哈希读取与判存，`DeleteAsync` 删除；相同内容只存一份，适合资源与下载缓存复用。

## 直接代码要点

- **运行流程**：写入时先计算内容哈希 → 以哈希为键落盘（已存在则复用）→ 读取/判存/删除均以哈希键定位。
- **输入输出规范**：输入为字节/流内容，输出为哈希键（字符串）或内容本身；`PutAsync` 为异步，读取为同步。
- **使用约束与注意事项**：哈希碰撞概率极低但需知晓；并发写入同一内容应保证幂等；删除为引用无关的物理删除，调用方需自行确认无其他引用。
