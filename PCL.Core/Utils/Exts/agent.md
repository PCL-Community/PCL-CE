# Utils/Exts 目录

扩展方法，位于命名空间 `PCL.Core.Utils.Exts`。为常见类型（字节、字符串、集合、HTTP、任务、UI 等）补充扩展方法。

## 本目录模块

- **ByteExtension.cs**：字节/字节数组扩展。
- **StringExtension.cs**：字符串扩展。
- **ListExtension.cs**：列表扩展。
- **ConcurrentDictionaryExtension.cs**：并发字典扩展。
- **AsyncEnumerableExtensions.cs**：异步可枚举扩展。
- **HttpRequestExtension.cs**：HTTP 请求扩展。
- **TaskExtension.cs**：Task 扩展（超时、安全等待等）。
- **UiExtension.cs**：UI 元素扩展（WPF）。
- **LanguageSpecificStringDictionaryExtensions.cs**：语言特定字符串字典扩展（多语言文本字典取值）。
