# Minecraft/ResourceProject/Curseforge 目录

CurseForge 数据模型，位于命名空间 `PCL.Core.Minecraft.ResourceProject.Curseforge`。描述 CurseForge 项目/文件的 API 响应结构。

## 本目录模块

- **CurseforgeProject.cs**：CurseForge 项目主模型。
- **CurseforgeFile.cs**：文件模型（版本、下载）。
- **CurseforgeAuthors.cs**：作者模型。
- **CurseforgeCategories.cs**：分类模型。
- **CurseforgeHashes.cs**：哈希模型（指纹）。
- **CurseforgeLinks.cs**：链接模型。
- **CurseforgePictures.cs**：图片模型。
- **CurseforgeScreenshots.cs**：截图模型。
- **CurseforgeResponseData.cs**：响应数据包装模型。
