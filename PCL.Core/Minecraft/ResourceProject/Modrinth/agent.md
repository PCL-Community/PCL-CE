# Minecraft/ResourceProject/Modrinth 目录

Modrinth 数据模型，位于命名空间 `PCL.Core.Minecraft.ResourceProject.Modrinth`。描述 Modrinth 项目/版本的 API 响应结构。

## 本目录模块

- **ModrinthProject.cs**：Modrinth 项目主模型。
- **ModrinthLicense.cs**：许可证模型。
- **ModrinthGallery.cs**：画廊图片模型。
- **ModrinthDonationUrl.cs**：捐赠链接模型。
- **ModrinthModeratorMessage.cs**：审核消息模型。
