# Minecraft/IdentityModel/Extensions 目录

认证协议扩展容器，位于命名空间 `PCL.Core.Minecraft.IdentityModel.Extensions`。聚合多种身份认证协议的可复用客户端与元数据实现。

## 子目录导航

- [JsonWebToken](./JsonWebToken/agent.md)：JSON Web Token 与密钥。
- [OpenId](./OpenId/agent.md)：OpenID Connect 客户端。
- [Pkce](./Pkce/agent.md)：PKCE 质询。
- [YggdrasilConnect](./YggdrasilConnect/agent.md)：Yggdrasil Connect 客户端。
