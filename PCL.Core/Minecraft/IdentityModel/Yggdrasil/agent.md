# Minecraft/IdentityModel/Yggdrasil 目录

经典 Yggdrasil 认证，位于命名空间 `PCL.Core.Minecraft.IdentityModel.Yggdrasil`。封装 Mojang 传统 Yggdrasil 认证协议的客户端与数据模型。

## 本目录模块

- **Client.cs**：Yggdrasil 客户端（登录/刷新令牌）。
- **Options.cs**：客户端选项。
- **Agent.cs**：认证代理模型（游戏/版本标识）。
- **Profile.cs**：Yggdrasil 档案模型。
- **YggdrasilCredential.cs**：Yggdrasil 凭据模型（令牌等）。
