# Minecraft/IdentityModel/OAuth 目录

OAuth 客户端，位于命名空间 `PCL.Core.Minecraft.IdentityModel.OAuth`。实现 Minecraft/Microsoft 认证所需的 OAuth 2.0 授权流程。

## 本目录模块

- **IOAuthClient.cs**：OAuth 客户端接口。
- **Client.cs**：OAuth 客户端实现。
- **ClientOptions.cs**：客户端选项（clientId、scope、端点等）。
- **AuthorizeResult.cs**：授权结果模型。
- **DeviceCodeData.cs**：设备码（Device Code）流程数据。
- **EndpointMeta.cs**：端点元数据模型。
