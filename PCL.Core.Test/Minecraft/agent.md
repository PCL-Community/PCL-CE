# Minecraft 测试分组

本目录测试 PCL.Core 中与 Minecraft 相关的核心逻辑：本地 Java 运行时探测、存档（Save）扫描/加载/编辑/导入、服务器 ping、玩家档案（Profile）管理，以及 Mod 资源依赖解析。

## 本目录测试模块

本目录（不含子目录 `ResourceProject`）直接包含以下测试类。`JavaTest.cs` 实为父项目根目录（`PCL.Core.Test/JavaTest.cs`）的文件，按"保留既有内容"约束在此保留其条目，但其源码不在此目录内。

- `JavaTest.cs` — `JavaManager` 组合多扫描器（注册表/默认路径/环境变量/商店/where）扫描本地 Java，验证结果列表稳定可排序（`PCL.Core.Minecraft.Java`）。源码位于父项目根目录，详见 `../JavaTest.cs`。
- `SaveManagerTest.cs` — 存档管理器（`PCL.Core.Minecraft.Saves.SaveManager` 及 `Saves.Parsing`/`Saves.Editing`/`Saves.Exceptions`，命名空间 `PCL.Core.Test.Minecraft`）。
  - 覆盖模块：存档扫描 `ScanSaveFoldersAsync`、单/批量加载 `LoadSaveAsync`/`LoadSavesAsync`、编辑落盘 `ApplyChangesAsync`；解析工厂 `SaveParserFactory`、编辑器 `ISaveEditor`/`ISaveParser`、变更模型 `SaveChanges`/`Editable<T>`。
  - 测试编排：`[TestInitialize]` 在 `Path.GetTempPath()/PCLTest/{Guid}` 建临时根并 `new SaveManager()`；`[TestCleanup]` 递归删除；辅助 `WriteLevelDat` 用 `fNbt` 以 GZip 写入 `level.dat`（Data 复合标签）模拟各版本存档。
  - 关键用例：空目录返回空列表；有效存档返回 `LevelName`/`GameMode`（如 `GameType=1→Creative`）；跳过无 `level.dat` 的文件夹；四代格式解析——Pre-Legacy（`RandomSeed`/SpawnX/Y/Z）、Legacy（`allowCommands`/`Difficulty`/`hardcore`）、Modern（`DataVersion`/`Version` 复合）、NextGen（`difficulty_settings` 字符串难度、`spawn.pos` 数组）。
  - 边界与异常：`level.dat_old` 回退、`SaveNotFoundException`（无 level.dat）、`SaveCorruptedException`（损坏文件 / 无匹配解析器 / 无匹配编辑器）；`Seed` 来源优先级（`WorldGenSettings.seed`→`RandomSeed`→外部 `data/minecraft/world_gen_settings.dat`）；`ApplyChangesAsync` 编辑 `AllowCommands`/`Difficulty`/`LockDifficulty`、空变更返回 `false`、编辑前保留 `level.dat_old` 备份。
- `SaveImportHelperTest.cs` — 存档导入根目录判定（`PCL.Core.Minecraft.SaveImportHelper`）。
  - 测试编排：`[TestInitialize]`/`[TestCleanup]` 在临时目录创建/清理；每个用例在临时树下布置不同结构后调用 `GetSaveRootDirectory`。
  - 关键用例：根目录直接含 `level.dat` 时返回根；仅一个含 `level.dat` 的顶层文件夹时"拍平"返回该文件夹（即使根目录另有 `thumbs.db` 等杂项文件）；顶层文件夹无 `level.dat`、或存在多个顶层文件夹时返回 `null`（拒绝歧义结构）。
- `McPing.cs` — 服务器 ping（`PCL.Core.Link.McPing.McPingServiceFactory`，注意其命名空间为 `PCL.Core.Link` 而非 `PCL.Core.Minecraft`）。
  - 关键用例：`PingTest` 用 `McPingServiceFactory.CreateService` 对真实服务器 `mc.hypixel.net:25565` 与 `mc233.cn:25565` 调用 `PingAsync`，断言返回非 `null` 并输出 `Description`（MOTD）。**需联网、非确定性**。
- `ProfileManagementTest.cs` — 玩家档案集合管理（`PCL.Core.Minecraft.Profile` / `PCL.Core.Minecraft.Profile.Models`，泛型 `ProfileManagement<McProfile>`）。
  - 关键用例：`LoadSerializeRoundTripPreservesProfileData` 用 `LoadFromString` 载入含 `McProfile`（ProfileId/Type/UserName/Uuid/令牌/Server/密码等）的 JSON，`Serialize`→`LoadFromString` 往返后字段、`Current`、`LastUsed=0` 全部保留；`SelectionAndUpdateUseStableProfileIdentity` 验证 `Add`/`Select`/`Update`（按 ProfileId 身份更新，`Clone` 后改名）后 `Current` 与索引正确、`LastUsed=1`；`DeleteSelectedProfileClearsSelectionAndLastUsed`（删除已选→`Current=null`、`LastUsed=-1`）；`DeleteProfileBeforeSelectionKeepsSelectedProfile`；`UpdateRejectsDuplicateProfileIdentity` 对重复 ProfileId 的更新抛 `InvalidOperationException`。

## 运行流程（测试编排）

- 纯逻辑类（`SaveManagerTest`、`SaveImportHelperTest`、`ProfileManagementTest`）统一使用临时目录夹具：`[TestInitialize]` 建 `Path.GetTempPath()/PCLTest/.../{Guid}`、`[TestCleanup]` 递归删除，互不污染。
- `SaveManagerTest` 大量用例经辅助方法 `WriteLevelDat(folder, populateData)` 以内联 `Action<fNbt.NbtCompound>` 构造不同版本/字段的 `level.dat`，再用断言回读校验，形成"写 NBT→解析→断言"的闭环。
- `McPing.cs` 为网络集成用例，依赖 `TestContext.CancellationToken`，对外部服务器发起真实 TCP/协议握手，结果随网络与服务端变化。
- 命名空间约定：本目录测试类位于 `PCL.Core.Test.Minecraft`，对应 PCL.Core 的 `PCL.Core.Minecraft.*`（McPing 除外，对应 `PCL.Core.Link.McPing`）。

## 输入输出规范（被测 API 与夹具）

- 被测 API：`SaveManager.{ScanSaveFoldersAsync, LoadSaveAsync, LoadSavesAsync, ApplyChangesAsync}`、`SaveImportHelper.GetSaveRootDirectory`、`McPingServiceFactory.CreateService(...).PingAsync`、`ProfileManagement<McProfile>.{LoadFromString, Serialize, Add, Select, Update, Delete, GetAll, Current, LastUsed}`。
- 夹具：`level.dat` 由 `fNbt.NbtFile` + GZip 生成；外部种子文件 `data/minecraft/world_gen_settings.dat` 亦为 GZip NBT；`McProfile` 经 System.Text.Json 序列化为 launcher 档案 JSON。
- 断言风格：`Assert.AreEqual`/`IsTrue`/`IsNull`/`AreSame`/`ThrowsExactly<InvalidOperationException>`/`ThrowsExactlyAsync<SaveNotFoundException|SaveCorruptedException>`；`McPing` 仅 `Assert.IsNotNull` + 打印。

## 使用约束与注意事项

- 需联网/外部服务：`McPing.cs` 对 `mc.hypixel.net`、`mc233.cn` 发起真实 ping，非确定性，**CI 中应忽略或隔离**（建议 `[Ignore]` 或按标签筛选）。
- `JavaTest.cs` 虽在本目录文档列出，但其源码位于父项目根目录（`../JavaTest.cs`），扫描本机 Java，同样依赖运行环境、结果非确定，运行本目录测试时不会自动包含该文件（取决于 MSTest 发现范围）。
- 纯确定性、可离线：`SaveManagerTest`、`SaveImportHelperTest`、`ProfileManagementTest` 全部基于临时目录与内存 NBT，适合 CI 稳定执行。
- `SaveManagerTest` 头部注释标明 `// Generated by deepseek-v4-pro`，覆盖四代存档格式与主要异常路径；若 PCL.Core 存档格式变更需同步维护 `WriteLevelDat` 与各断言。
