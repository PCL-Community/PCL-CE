# PipeServer 资源管理问题分析与解决方案

## 1. 问题分析

### 1.1 生命周期依赖关系

- **当前实现**：`PipeServer` 类持有 `NamedPipeServerStream` 作为属性
- **潜在问题**：如果 `PipeServer` 实例被 GC 回收，而返回的 `PipeServerStream` 仍在使用，可能导致资源管理混乱
- **根本原因**：调用者只持有 `Stream` 引用，而不持有 `PipeServer` 实例引用，导致 `PipeServer` 实例可能被提前回收

### 1.2 资源管理风险

1. **GC 回收时机问题**：`PipeServer` 实例可能在 `Stream` 仍在使用时被回收
2. **资源释放不完整**：`PipeServer` 中的其他资源（如回调函数引用）可能无法正确释放
3. **状态管理混乱**：`PipeServer` 中的状态变量（如 `_isConnected`）可能在 Stream 使用过程中变得无效
4. **线程安全问题**：多线程环境下可能出现资源竞争

## 2. 解决方案

### 2.1 方案概述

创建一个静态工厂类 `PipeServerFactory`，负责：
1. 创建 `PipeServer` 实例
2. 管理实例生命周期
3. 提供与原 API 兼容的静态方法
4. 确保资源正确释放

#### 2.2.2 创建 PipeServerFactory.cs

```csharp
namespace PCL.Core.IO.Pipe;

/// <summary>
/// PipeServer 工厂类，负责创建和管理 PipeServer 实例
/// </summary>
public static class PipeServerFactory
{
    // 存储活跃的 PipeServer 实例，防止被 GC 回收
    private static readonly List<PipeServer> _activeServers = new();
    private static readonly object _lock = new();

    /// <summary>
    /// 创建并启动 PipeServer 实例
    /// </summary>
    /// <returns>创建的 PipeServer 实例</returns>
    public static PipeServer CreateAndStartServer(
        string pipeName,
        string identifier,
        bool stopWhenException,
        Func<StreamReader, StreamWriter, Process?, bool> loopCallback,
        Action? stopCallback = null,
        int[]? allowedProcessId = null)
    {
        // 创建服务器实例
        var server = new PipeServer(
            pipeName, identifier, stopWhenException, loopCallback, 
            () => {
                // 服务器停止时从活跃列表中移除
                RemoveServer(server);
                stopCallback?.Invoke();
            }, 
            allowedProcessId);

        // 添加到活跃列表
        AddServer(server);

        // 启动服务器
        server.Start();

        return server;
    }

    /// <summary>
    /// 添加服务器到活跃列表
    /// </summary>
    private static void AddServer(PipeServer server)
    {
        lock (_lock)
        {
            _activeServers.Add(server);
        }
    }

    /// <summary>
    /// 从活跃列表中移除服务器
    /// </summary>
    private static void RemoveServer(PipeServer server)
    {
        lock (_lock)
        {
            _activeServers.Remove(server);
        }
    }
}
```
