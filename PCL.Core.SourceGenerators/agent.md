# PCL.Core.SourceGenerators

PCL2（Plain Craft Launcher 2）的 **Roslyn 源代码生成器** 项目。在编译期为 `PCL.Core` 自动生成代码（配置系统、依赖注入、生命周期管理、环境变量注入等），无需运行时反射。

- 目标框架：`netstandard2.0`，C# `latest`，启用 `Nullable`。
- 引用：`Microsoft.CodeAnalysis.CSharp` / `Microsoft.CodeAnalysis.Analyzers` 5.6.0（`PrivateAssets=all`，仅生成器自身使用）。
- 编译选项：`EnforceExtendedAnalyzerRules=true`；目标平台 `AnyCPU;x64;ARM64`（强制 `PlatformTarget=AnyCPU`，保证生成器在各架构下正常加载）；配置 `Debug;CI;Release;Beta`。
- 所有生成器均为 `IIncrementalGenerator`（增量生成，基于 `SyntaxProvider`/`AdditionalTextsProvider`，支持缓存与增量重编译）。
- 排除目录：`bin/`、`obj/`（构建产物，不含源码）。

## 直接包含的文件与职责

### 生成器（含 `[Generator]` 特性）

- **`ConfigGenerator.cs`** — `ConfigGenerator : IIncrementalGenerator`
  为配置系统生成代码，扫描以下特性（`PCL.Core.App.Configuration` 命名空间）：
  - `[ConfigItem<T>]` / `[AnyConfigItem<T>]` 标记的属性 → 顶层配置项 `XXXConfig`（类型为 `ConfigItem<T>`），并生成 `get/set` 访问器（普通类型）或带参访问器（`ArgConfig<T>` 场景）。
  - `[ConfigGroup]` 标记的类 → 嵌套作用域类（实现 `IConfigScope`），含 `SINGLE_INSTANCE`、`CheckScope`/`Reset`/`IsDefault` 实现，并递归收集子组与项。
  - `partial` 类（默认除 `[ConfigGroup]` 外）→ 为其生成 `partial class` 骨架，组装项与组的层级树。
  - `[RegisterConfigEvent]` 标记的公用静态属性 → 事件观察器注册。
  - 输出：每个 Config 类一个 `<Namespace>.<Config>.g.cs`；统一生成 `ConfigService.g.cs`，内含 `_InitializeConfigItems()`（注册 `(key, ConfigItem)` 表）与 `_InitializeObservers()`（注册 `ConfigEventRegistry`）。
  收集使用 `CreateSyntaxProvider` 分别匹配属性/类/事件，最后 `Combine` + `RegisterSourceOutput` 生成。

- **`DependencyCollectorGenerator.cs`** — `DependencyCollectorGenerator : IIncrementalGenerator`
  实现编译期依赖注入（DI）收集与注入：
  - 扫描带有 `[DependencyCollector<T>]`（`DependencyCollectorAttribute`，泛型）的**注解类**，提取依赖类型、`identifier`、`AttributeTargets` 范围（Class/Method/Property）。
  - 匹配被这些 collector 注解标记的 `static` 成员（类/属性/方法）→ `DependencyMatchResult`。
  - 扫描 `[DependencyInjectionPoint]`（`DependencyInjectionPointAttribute`）标记的方法 → 注入点，按 `identifier` 关联对应依赖集合。
  - 输出：
    - `DependencyGroups.g.cs`：`DependencyGroups` 静态类的 `_GroupMap`，按 identifier 分组存储 `DependencyGroup`（Class→`Action<T>` 工厂、Method→委托、Property→`PropertyAccessor<T>`）。
    - 每个注入点方法生成 `<QualifiedName>.g.cs`：生成 `<Method>_InvokeInjection_<Id>()`，调用依赖项并传入构造参数。
  使用 `ForAttributeWithMetadataName` 与 `CreateSyntaxProvider` 组合。

- **`EnvironmentInteropGenerator.cs`** — `EnvironmentInteropGenerator : IIncrementalGenerator`
  读取进程环境变量生成密钥字典：
  - 若设置了 `PCL_WRITE_SECRET`，收集所有以 `PCL_` 开头（除自身外）的环境变量，去掉 `PCL_` 前缀作为键。
  - 输出 `namespace PCL.Core.Utils.OS` 下的 `partial class EnvironmentInterop`，含 `SecretDictionary`（`Dictionary<string,string?>`）初始化。
  - 注意：直接读取 `Environment.GetEnvironmentVariables()`（触发 RS1035 抑制），非通过 MSBuild 属性。

- **`LifecycleScopeGenerator.cs`** — `LifecycleScopeGenerator : IIncrementalGenerator`
  为声明 `[LifecycleScope]`（`LifecycleScopeAttribute`）的 `partial class` 生成 `ILifecycleService` 实现：
  - 解析作用域 `Identifier`、`Name`、`SupportAsync`（是否异步启动）构造参数。
  - 扫描类内方法上的特性：`[LifecycleStart]`、`[LifecycleStop]`、`[LifecycleCommandHandler]`、`[LifecycleDependencyInjection]`、`[DependencyInjectionPoint]`。
  - 输出 `<Namespace>.<Type>.g.cs`：实现 `Identifier`/`Name`/`SupportAsync` 属性、`StartAsync()`（按顺序调用 Start/Command/DI 方法，无 Stop 则声明已停止）、`StopAsync()`（调用 Stop 方法）。
  - 命令处理方法生成 `Essentials.StartupService.TryHandleCommand(...)` 调用并解析参数；DI 方法通过 `DependencyGroups.InvokeInjection(...)` 调用；新注入点调用前述 `*_InvokeInjection_*` 方法。

- **`LifecycleServiceTypesGenerator.cs`** — `LifecycleServiceTypesGenerator : IIncrementalGenerator`
  汇总生命周期服务类型：
  - 通过 `AdditionalTextsProvider` 读取 `LifecycleState.cs`，用正则解析有效枚举值作为合法状态。
  - 扫描带 `LifecycleService` 特性的类，解析其状态参数（如 `LifecycleState.XXX`）与 `Priority`（支持字面量、命名参数、简单算术表达式、常量）。
  - 输出 `LifecycleServiceTypes.g.cs`（`namespace PCL.Core.App.IoC`）：按状态分组的 `Type[]` 静态数组、以及 `GetServiceTypes(state)` / `GetAllServiceTypes()` / `GetStatistics()` 方法（同状态内按 Priority 降序）。

### 共享辅助代码（非生成器，被上列生成器复用）

- **`SharedConstants.cs`** — 共享常量，集中定义各特性与命名空间的元数据全名（`AppNamespace=PCL.Core.App`、`IocNamespace`、`DependencyCollectorAttribute`、`DependencyInjectionPointAttribute`、`LifecycleScopeAttribute`、`LifecycleStart/Stop/CommandHandler/DependencyInjectionAttribute` 等），供各生成器按名称匹配特性。

- **`SharedExtensions.cs`** — 共享扩展方法，提供生成代码所需的字符串/符号工具：
  - `ToLiteral`/`ToPrimitive`（字面量格式化）、`GetDeclarationOrder`（声明顺序）。
  - 类型/符号扩展：`GetSimplifiedTypeName`、`GetFullyQualifiedName`、`GetQualifiedSymbolName`、`TryGetSpecialTypeKeyword`、`IsPartial`、`IsNestedWithin`、`IsAttribute`、`GenerateTypeHeader`（生成命名空间/外层类/类头）。
  - `RenderDefaultValueCode`（将默认值的 `ExpressionSyntax` 渲染为代码，支持字面量、`typeof`、`nameof`、字段引用）、`IsNegativeNumeric`、`CorrectConfigTypeName`、`GetQualifiedPropertyAccess`、`IsAwaitable`、`SnakeIdToPascal`。

- **`System.Runtime.CompilerServices.cs`** — 占位类型 `IsExternalInit`，为 `netstandard2.0` 提供 `init` 关键字/记录类型支持（否则无法使用 `init` 访问器与 `record`）。

## 关键约定与边界

- 仅描述本目录的源码职责；生成器的具体特性语义（如 `LifecycleState.cs`、`ConfigItemAttribute` 定义）位于 `PCL.Core` 主项目，不在本目录范围。
- 所有生成代码均带 `// <auto-generated />` 头，禁止手动修改。
- 生成器之间无相互依赖，仅通过 `SharedConstants`/`SharedExtensions` 共享基础设施。
